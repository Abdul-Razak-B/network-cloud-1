Sub-topic 1.6.1 Cloud Paradigm

Cloud Computing Fundamentals & Essential Characteristics

Demystifying the utility-based shift from legacy on-premises physical data centers to elastic cloud systems.

What is Cloud Computing?

Cloud computing is the on-demand access to virtualized computing resources (servers, databases, storage, software, and networking) delivered over the internet with a pay-as-you-go economic model. Rather than purchasing and housing expensive server hardware, institutions rent computing power dynamically from hyperscale providers.

Real-Life Pedagogical Analogy: The Municipal Electricity Grid

When you plug a smartboard or air conditioner into a wall socket at IBA Public School Sukkur, you do not construct a personal hydroelectric dam or diesel generator. You simply draw electric power from the public utility grid and pay strictly for the kilowatt-hours consumed. Cloud computing functions on this exact utility model.

CapEx to OpEx Paradigm Shift

Legacy CapEx (Capital Expenditure): Massive upfront investments in server racks, cooling, UPS generators, and long procurement cycles with idle capacity waste.
Modern OpEx (Operational Expenditure): Predictable, flexible monthly operational subscriptions. Spend only for what your active students and web services consume.
Enables schools, startups, and universities to access enterprise-grade infrastructure instantly without millions in capital.

5 Essential Characteristics (NIST SP 800-145 Benchmark)

01
On-Demand Self-Service

Users provision compute capabilities (server time, cloud storage) autonomously without human intervention from the provider.

02
Broad Network Access

Capabilities are accessible over standard networks via laptops, smartphones, tablets, and classroom workstations anywhere.

03
Resource Pooling

Provider compute assets are dynamically pooled in multi-tenant datacenters and reassigned on demand according to consumer traffic.

04
Rapid Elasticity

Resources scale out instantaneously during annual exam result checks and scale inward during semester breaks to eliminate waste.

05
Measured Service

Resource usage is monitored, controlled, and billed with complete transparency for bandwidth, storage volumes, and CPU hours.

Vendor Manages: Physical Servers, Virtualization Hypervisors, Storage Disks, Datacenter HVAC & power.

PaaS

Platform as a Service

You Manage: Application Source Code, Database Schemas, Logic, API configurations.
Vendor Manages: OS Security Patches, Runtime Engines (Node/Python/Java), Auto-scaling, Infrastructure.
Industry Examples:
Google App Engine Heroku AWS Elastic Beanstalk
Application Layer Zero Maintenance

SaaS

Software as a Service

You Manage: User Access Logins, Passwords, School Data Entry, Application Permissions.
Vendor Manages: Entire Software Stack, Feature Updates, Security Patches, Hosting & High Availability.
Industry Examples:
Google Workspace / Drive Microsoft 365 Google Classroom
Sub-topic 1.6.3 Deployment Models

Cloud Deployment Architectures

Categorizing cloud boundaries based on multi-tenancy, privacy governance, and physical data jurisdiction.

Multi-Tenant

Public Cloud

Infrastructure owned by commercial third-party providers (AWS, Azure) and delivered publicly across open internet lines to anyone subscribing.

🚗 Real Analogy: A public city transit bus shared by multiple passengers commuting along public roads.
Dedicated

Private Cloud

Cloud infrastructure operated solely for a single organization (e.g., Banking data centers, Defense intelligence intranet).

🚗 Real Analogy: Your personal private family car parked securely inside your own garage with exclusive access.
Shared Mission

Community Cloud

Shared infrastructure mutually utilized by organizations with shared regulatory needs or scientific research domains (e.g., Sindh Universities Research Cloud).

🚗 Real Analogy: A university student shuttle van pooled and shared cooperatively between regional campuses in Sukkur.
Integrated

Hybrid Cloud

Combines private and public clouds connected through encrypted VPN tunnels (e.g., IBA Sukkur keeping student grades on-premises while hosting public event portals on AWS).

🚗 Real Analogy: Driving your private car to the city terminal, then boarding the express public train to travel across provinces.
